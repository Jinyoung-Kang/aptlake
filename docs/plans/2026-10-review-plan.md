## 2. 목표 구조

### 백엔드 (API) — 기능별 3계층, 의존은 바깥 → 업무 규칙 한 방향
```
api/src/aptlake_api/
  core/        설정·오류(Problem)·응답 헤더/캐시(respond)·인증·리소스 — 기존 코드 이동
  features/
    regions/   router.py  →  service.py  ←  repository.py
    trades/    (router: FastAPI·스코프·파라미터 검증만 / service: 순수 업무 규칙, FastAPI·DB 를 모름 /
    market/     repository: SQL 만, service 가 정의한 Protocol 을 구현)
    index/ quality/ ops/ exports/ admin/ ...
```
- `service` 는 FastAPI·ClickHouse·psycopg 를 import 하지 않는다 → **아키텍처 테스트**로 강제(import 검사).
- 공개 API 의 URL·응답 모양은 바꾸지 않는다 → 리팩터링 전에 **모든 공개 GET 응답을 골든 파일로 고정**하고 커밋마다 비교.
- 새 프레임워크·DI 컨테이너는 넣지 않는다 (함수 인자로 repository 를 넘김).

### 파이프라인
- 센서의 실행 계획을 `scheduling.py` 순수 함수로 (입력: 기한 도래 파티션·진행 중 실행·예산 / 출력: 실행 요청 목록). Dagster 정의는 조립만.

### 프런트엔드 — 그리기와 로직 분리
```
web/src/
  api/         client.ts(요청·재시도·캐시·오류) + endpoints.ts(엔드포인트별 타입 있는 함수) + types.ts
  domain/      React 에 의존하지 않는 순수 함수: 지표 값·구간, 월 채우기·전년비, 거래 조건, 큐 정렬, 품질 집계…
  hooks/       상태·부수효과: useResource, useTradesPager, useNow, useOpsLog …
  components/  그리기만 (props 입력)
  pages/       hooks + components 조립
```
- 도구: **Vitest**(순수 함수·클라이언트 테스트), **ESLint + react-hooks 규칙**(Hook 의존성 누락 탐지). 개발 의존성만, 런타임 추가 없음.
- 작은 중복까지 추상화하지 않는다. 상태 관리 라이브러리·라우터 교체는 하지 않는다.

### UI/UX — Palantir(Blueprint) 원칙: 시인성·명시성·가독성
라이브러리 도입 없이 디자인 토큰과 컴포넌트 CSS 로:
- **시인성**: 밝은/어두운 테마 모두 본문 대비 4.5:1 이상(스크립트로 검증), 의도 색(정보·성공·경고·위험)은 상승/하락 색과 분리, 초점 테두리 항상 표시.
- **명시성**: 모든 숫자 열·지표에 단위와 기준(기준월·자료 버전) 표기, 상태는 색 + 아이콘 + 글자, 잠정·표본 부족을 숨기지 않음.
- **가독성**: 숫자는 고정폭 숫자(tabular-nums)·오른쪽 정렬, 조밀한 표 + 고정 머리글, 글자 크기 단계 정리, 장식 줄임.
- 기본 테마는 **OS 설정을 따름**(직접 바꾼 선택은 기억). 전후 화면 캡처로 비교.

## 4. 승인해 주셔야 할 결정 (권장안 표시)
1. **ClickHouse 25.8 → 26.8 LTS 업그레이드** — 서빙 DB 엔진 버전을 올리면 디스크 형식이 바뀌어 되돌리기 어렵습니다. 서빙 데이터는 레이크에서 다시 발행할 수 있고, 올리기 전에 백업(H4)을 먼저 만듭니다. **권장: 진행**
2. **Prometheus 3.14 → 3.13 LTS** — 버전을 내리는 것이라 기존 지표 저장소를 못 읽으면 운영 지표 이력(최대 15일)을 비웁니다. 서비스 데이터와 무관합니다. **권장: 진행(필요 시 지표 이력 초기화)**
3. **결과 반영 방식** — 브랜치를 GitHub 에 올리고 PR 을 만들어 CI 를 통과시킵니다. main 병합은 검토 후 직접 하시거나 지시해 주세요. 로컬 스택은 검증을 위해 이 브랜치로 재배포합니다. **권장: PR 까지**
4. **UI 기본 테마** — OS 설정을 따름(밝게/어둡게 직접 선택 가능). **권장: OS 설정 따름**

이 밖에 공개 API 변경·기능 삭제·유료 서비스·직접 넣어야 할 비밀값은 계획에 없습니다. 진행 중 생기면 그때 멈추고 여쭙겠습니다.
